# Проект по Математической Статистике

Данный проект включает практические работы по теме **"Математическая статистика"** и демонстрирует навыки работы с гипотезами, распределениями и статистическими метриками.

---

## Основной функционал

1. **Работа с распределениями**
   - Построение и анализ различных распределений (нормальное, биномиальное, пуассоновское и др.).
   - Визуализация распределений с помощью графиков.

2. **Работа с математической статистикой**
   - Расчёт основных статистических метрик: среднее, медиана, мода, дисперсия, стандартное отклонение.
   - Анализ данных и интерпретация результатов.

3. **Работа с гипотезами**
   - Формулировка нулевой и альтернативной гипотез.
   - Проверка гипотез с использованием t-теста, chi-square теста и других статистических методов.
   - Интерпретация p-value и уровня значимости.

---

## Цель проекта

- Закрепление теоретических знаний по математической статистике на практике.
- Развитие навыков анализа данных и визуализации статистической информации.
- Практика проверки гипотез и интерпретации результатов.

---

## Технологии

- Python 3
- NumPy, SciPy — для математических и статистических расчётов
- Statsmodels — для продвинутого статистического анализа и проверки гипотез
- Matplotlib, Seaborn — для визуализации данных
- Jupyter Notebook — для демонстрации и анализа результатов

---

## Примечания

- Каждая работа оформлена как отдельный Jupyter Notebook.
- Проект предназначен для учебных целей и закрепления практических навыков по математической статистике.
